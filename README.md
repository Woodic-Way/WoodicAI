## 📖 About

**Woodic AI** is a free, open-source Android application that connects to multiple AI service providers and responds fluently in Persian. The project was built with the goal of providing Persian speakers with easy access to AI assistants without any cost.

The app supports free services such as **Groq**, **Google Gemini**, **Cloudflare AI**, **OpenRouter**, and **Hugging Face**, allowing users to easily switch between them.

---

## ✨ Features

- 🤖 **Multiple free AI providers** — Groq, Gemini, Cloudflare, OpenRouter, and more
- 📷 **Image upload** — Analyze images with Vision models
- 📎 **Text file upload** — Up to 20 files at once (max 20 MB)
- 🌙 **Dark / Light mode** — Full DayNight support
- 💬 **Multiple simultaneous chats** — Auto-saved in local database
- 📋 **Code display with copy button** — Syntax highlighting and easy copy
- ➕ **Add custom providers** — Any service supporting the OpenAI format
- 🔄 **Automatic fallback** — Switches providers on error

## 🚀 Installation

### Download APK

1. Go to the [**Releases**](../../releases/latest) page
2. Download the latest `WoodicAI.apk`
3. Enable **"Install from unknown sources"** on your Android device
4. Install the APK and launch the app

### Requirements

- Android 6.0 (API 23) or higher
- Internet connection (VPN may be required in some regions)

---

## 📖 How to Use

1. Open the app
2. From the three-dot menu, select **"Add New Provider"**
3. Enter the provider details (name, API key, URL)
4. Select a model and start chatting!

### Adding a Custom Provider

| Field | Description |
|-------|-------------|
| Compatibility | OpenAI-style or Gemini-style |
| Name | Display name (e.g., Groq) |
| API Key | Your personal API key |
| Chat Completions URL | Provider's API endpoint |
| Models List URL | (Optional) |
| Default Model | (Required if models list is empty) |

---

## ⚠️ Important Note

> **Always use your own personal API key.**
>
> If you use a shared API key, no response will be received due to free-tier limitations. Each user must obtain their own API key from the provider and enter it in the app.
